## ADDED Requirements

### Requirement: Разложение по энергии

Сводка каталога MUST раскладывать энергию по фразам (одно значение на фразу), включая все значения словаря и ряд «без значения». Энергия MUST NOT входить в «топ тем» рядом с настроением и подачей.

#### Scenario: Сводка с энергией

- **GIVEN** две фразы с энергией «громко», одна с «шёпот», одна без энергии
- **WHEN** открывают сводку
- **THEN** громко = 2, шёпот = 1, без значения = 1, остальные ступени словаря = 0

#### Scenario: Пустой каталог по энергии

- **GIVEN** в базе нет фраз
- **WHEN** запрашивают сводку
- **THEN** счётчики энергии нули, интерфейс не падает
