## MODIFIED Requirements

### Requirement: Импорт Apple Notes через бота

Система MUST позволить любому вошедшему пользователю командой `/notes` открыть меню импорта Apple Notes. Команда MUST быть в Bot Commands (`setMyCommands`). Путь папки Notes MUST храниться отдельно для каждого пользователя (по умолчанию `Музыка/Рэпчик`, сегменты через `/`).

Меню MUST содержать кнопки: **FAQ**, **Настройки**, **Скрипт**, **Загрузить**.

- **FAQ** MUST прислать краткую инструкцию по-русски.
- **Настройки** MUST ждать текстовый путь папки Notes; кнопка **Отмена** (и `/notes cancel`) MUST сбрасывать ожидание.
- **Скрипт** MUST выдать `.applescript` под текущий путь. Скрипт MUST писать `.txt` с YAML `created`/`modified` в `Desktop/Dope Notes Export/`.
- **Загрузить** MUST открыть окно ожидания zip (~30 мин); кнопка **Отмена** (и `/notes cancel`) MUST сбрасывать ожидание.

Получив zip от пользователя в окне ожидания, система MUST распаковать `.txt` (`fflate`), импортировать как `source = APPLE_NOTES` с датами из YAML (тот же модуль, что CLI) **в каталог этого пользователя**, ответить счётчиками по-русски. Импорт MUST NOT попадать в чужой каталог. Пользователь без учётки MUST NOT запускать импорт. Повторный тот же набор MUST NOT плодить дубликаты по существующим правилам дедупа; дедуп MUST считаться в пределах каталога пользователя.

#### Scenario: Меню /notes

- **GIVEN** пользователь пишет `/notes`
- **WHEN** бот отвечает
- **THEN** приходит меню с кнопками FAQ, Настройки, Скрипт, Загрузить и его текущим путём Notes

#### Scenario: Выдача скрипта

- **GIVEN** пользователь в меню нажимает «Скрипт»
- **WHEN** бот отвечает
- **THEN** приходит файл `.applescript` под сохранённый путь и краткая подпись без обязательной строки `osascript`

#### Scenario: Импорт zip

- **GIVEN** пользователь нажал «Загрузить» и присылает zip с заметками
- **WHEN** бот обрабатывает документ
- **THEN** в его каталоге появляются/обновляются записи `APPLE_NOTES`, в ответе есть числа загруженных и обновлённых дат

#### Scenario: Импорт не течёт в чужой каталог

- **GIVEN** у авторов A и B есть свои каталоги
- **WHEN** автор B импортирует zip заметок
- **THEN** записи появляются только у автора B, каталог автора A не меняется

#### Scenario: Одинаковые номера заметок у разных авторов

- **GIVEN** у авторов A и B есть заметки с одинаковыми номерами в именах файлов
- **WHEN** оба импортируют свои архивы
- **THEN** у каждого в каталоге свои заметки, ни одна не отброшена как дубликат чужой

#### Scenario: Отмена кнопкой

- **GIVEN** пользователь ждёт путь или zip
- **WHEN** нажимает «Отмена»
- **THEN** последующий текст/zip не обрабатывается как часть этого ожидания
