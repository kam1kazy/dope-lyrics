## Why

Сводка уже считает корпус (`catalogStats`), но экран — плоская сетка чисел. Нужен дашборд как на макете: крупная цифра, активность по датам, топ граней и воронка готовности — чтобы видеть состав каталога одним взглядом, без ИИ.

## What Changes

- Переверстать раздел «Сводка» в панели каталога под дашборд (карточки, area-chart, полосы).
- Расширить `catalogStats`: дельта за 30 дней (`addedLastMonth`), глобальный топ настроения/подачи (`themes`).
- Новый query `catalogActivity(days)` — ряд по дням UTC для графика (7 / 30 / 90).
- На экране ролей — только имя и счётчик; mood/delivery внутри роли не дублировать (уходят в топ и «Без роли»).
- Зависимость `recharts` и kit-файл chart shadcn на клиенте.

### Modified Capabilities

- `catalog-analytics`: дашборд вместо плоского списка; график активности по `Lyrics.date`; глобальный топ mood+delivery; роли на экране без вложенных граней.

## Impact

- Сервер: `catalog-stats.ts`, `lyrics.service.ts`, GraphQL typeDefs/resolvers.
- Клиент: `catalog-stats` feature, `CATALOG_STATS` / новый query, типы `ICatalogStats`.
- Новые пакеты только в `client/`: `recharts` + shadcn chart.
- Prisma-схема не меняется. Фильтры карусели на сводку по-прежнему не действуют.

## Non-goals

- Фильтр «все время» на всю сводку (цифры — весь каталог; период только у графика).
- Хештеги Telegram в топе тем.
- Клик из сводки в отфильтрованный список.
- Аналитика youways (CQI/SHI), ИИ, сервер/домен/Mini App.
- Полировка UI как финальный дизайн.
