## Why

Случайный слот из одной фразы даёт дырявый каркас (пустые хуки) и простыню вместо куплета. Пункт меню «История» смешивает склейку с архивом лайков. Нужен генератор с формой хита, квотой размера и чисткой служебного текста.

## What Changes

- Пункт меню каталога: «Генератор» вместо «История». Сборка — основной экран раздела.
- Лайкнутые склейки — иконка в шапке генератора (как фильтр у списка), не отдельный пункт меню.
- Фильтр генератора: пресет формы (хит / полотно) и switch «Скрыть адлибы». Не фильтр списка (роли/теги).
- Слот — квота строк по роли, не один `lyricId`. Короткие фразы добираются, простыня режется окном.
- Второй хук в каркасе — повтор первого, не вторая случайная фраза.
- В тексте генератора и истории склеек: хештеги и `[квадратные скобки]` убирать всегда; `(круглые)` — только если включён switch.
- **BREAKING** для клиента: слот склейки хранит `parts` (фраза + диапазон строк), не один `lyricId`. Старые лайки с `lyricId` читаются как один кусок на весь текст.

Не входит: ИИ, пул по настроению/тегам списка, панчлайн/сцена в каркасе, слайдеры «ровно N», запись в Telegram, JWT.

## Capabilities

### New Capabilities

- `track-generator`: сборка по квоте формы хита/полотна, чистка текста, повтор хука, UI раздела «Генератор» и его фильтр.
- `generator-history`: лайкнутые склейки в иконке шапки генератора.

### Modified Capabilities

- (нет) В `openspec/specs/` ещё нет `track-assemble`; живой каркас остаётся `INTRO → VERSE → HOOK → VERSE → BRIDGE → HOOK`.

## Impact

- Сервер: `track-assemble.ts`, `lyrics.service.ts`, GraphQL (`assembleTrack` с пресетом и флагом адлибов, `CollageSlotInput.parts`).
- Prisma: JSON `LyricCollage.slots` — новый shape + чтение старого.
- Клиент: `catalog-menu.tsx`, `catalog-assemble`, типы/query entity lyric.
