## Context

См. proposal.md — Why. Живой каркас и лайк уже в `track-assemble.ts`, `lyrics.service.ts`, `catalog-assemble-panel.tsx`, пункт меню `history` в `catalog-menu.tsx`. JSON слотов: `{ songRole, lyricId }`. Telegram не участвует.

## Goals / Non-Goals

**Goals:**

- Квота строк на слот, окно по длинным фразам, повтор хука.
- Чистка `#` / `[]` всегда; `()` по флагу сборки и отображения.
- Меню «Генератор»; фильтр и история — иконки шапки, как фильтр у списка.

**Non-Goals:**

- Новый kit-файл shadcn Switch (переключатель в feature, без правки `shared/ui/shadcn`).
- Отдельная таблица кусков склейки; JSON остаётся.
- Фильтры пула как у списка.

## Decisions

### 1. Квоты в строках, абзац = 4

Считать непустые строки после чистки. Абзац = 4 строки, как `readinessFromLineCount`. Пресеты — константы рядом с `TRACK_FRAME`:

| слот | хит (default) | полотно |
| --- | --- | --- |
| INTRO | 2–4 | 2–4 |
| VERSE | 8–16 | 16 |
| HOOK | 4–8 | 4–8 |
| BRIDGE | 4–8 | 8–16 |

Не добрали min — показать сколько есть. Альтернатива «один lyric, фильтр по длине» отвергнута: каталог короткий + простыни.

### 2. Shape слота

`{ songRole, parts: [{ lyricId, startLine, endLine }] }`. `endLine` исключительный, индексы по очищенным строкам фразы. Пустой слот — `parts: []`. Чтение: если есть `lyricId` и нет `parts` — один кусок на все строки.

Альтернатива хранить готовый текст — ломает switch адлибов на истории.

### 3. API

`assembleTrack(preset: HIT | CANVAS, hideAdlibs: Boolean): AssembledTrack!` — не пишет в БД; грузит текст пулов, чистит, набирает квоту. Второй HOOK копирует `parts` первого. `likeCollage` валидирует длину каркаса и `parts`.

### 4. Чистка

Общая функция на сервере (квота) и клиенте (показ): убрать `#\S+`, убрать `[...]`, если hideAdlibs — убрать `(...)`, схлопнуть пустые строки. Карусель не вызывает её.

### 5. UI шапки

`catalog-menu.tsx`: секция `generator`. Иконки History и ListFilter; панели взаимоисключающие, выезд справа как у фильтра списка. Фильтр — не `CatalogFilterPane`, отдельная панель пресета + адлибы. История уезжает из низа `CatalogAssemblePanel`.

## Risks / Trade-offs

- [Мало хуков] → «нет хука», повтор не из чего копировать.
- [Старый JSON] → ветка в `slotsFromJson`.
- [Switch без пересборки] → клиент чистит показ; квота уже по прошлому флагу, пока не нажали «Собрать».

## Migration Plan

1. Расширить сборку и парсер JSON без миграции Prisma (JSON).
2. GraphQL parts + args assemble.
3. Меню и панели.
4. Откат: клиент снова один lyricId; старые лайки с parts история не нарисует без кода — не откатывать JSON.
