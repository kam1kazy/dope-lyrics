## Why

Пресеты «хит» и «полотно» зашивают длину слотов. Автору нужно задать своё число абзацев, а не выбирать из двух констант.

## What Changes

- В фильтре генератора поля длины слотов в абзацах: куплет и хук сразу видны; интро и бридж — за строкой «Показать ещё».
- «Хит» и «полотно» остаются пресетами: подставляют числа, их можно править.
- Число — целое ≥ 0, без верхней границы в UI. 0 = слот не набирать.
- Настройки формы (пресет и четыре числа) пишутся в `localStorage`.
- **BREAKING** для клиента: `assembleTrack` принимает квоты слотов, а не только `TrackFormPreset`. Пресет на сервере больше не выбирает диапазон сам.

### Modified Capabilities

- `track-generator`: квота слота — выбранное число абзацев, а не диапазон пресета; UI полей и сохранение в `localStorage`.

## Impact

- GraphQL: `assembleTrack` — input квот (абзацы по ролям); `preset` можно оставить для совместимости UI или убрать, если клиент шлёт только числа.
- Сервер: `track-assemble.ts`, `lyrics.service.ts`, резолвер.
- Клиент: `catalog-generator-pane.tsx`, `catalog-menu.tsx`, query `assembleTrack`.
- Prisma: без миграции.

## Non-goals

- Менять размер абзаца (по-прежнему 4 строки) и окно нарезки длинной фразы.
- Сохранять квоты в БД / на пользователя.
- ИИ, шов, запись в Telegram, полировка UI как финальный дизайн.
