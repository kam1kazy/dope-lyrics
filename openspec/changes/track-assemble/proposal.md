## Why

Каталог уже режет фразы по ролям в песне. Следующий шаг дорожки E без ИИ — собрать из этих кусков черновик трека случайной склейкой и сохранить удачную попытку лайком. Иначе роли остаются только фильтром и сводкой, а склейка «по смыслу» из vision не начинается.

## What Changes

- Случайная сборка трека по фиксированному каркасу ролей: `INTRO → VERSE → HOOK → VERSE → BRIDGE → HOOK`.
- Пул на слот: фразы с этой `songRole`, включая скрытые; цензура не участвует.
- Пустой пул — слот «нет кусков», без падения.
- В одном черновике одна фраза не повторяется, если пул позволяет.
- Лайк сохраняет черновик в базу; без лайка ничего не пишется.
- Раздел меню «История» становится живым: список лайкнутых склеек; сверху — сборка («Собрать», слоты, лайк).
- Заглушка `generations` снимается.

## Capabilities

### New Capabilities

- `track-assemble`: случайная склейка кусков по ролям и сохранение лайком.
- `collage-history`: список сохранённых склеек в меню каталога.

### Modified Capabilities

- (нет) Каталог и сводка не меняют требования; только UI-меню открывает живой раздел.

## Impact

- Prisma: модель `LyricCollage` (слоты JSON).
- GraphQL: `assembleTrack`, `likeCollage`, `lyricCollages`.
- Клиент: панель в меню каталога; feature `catalog-assemble` / история.
- Telegram, ИИ, ручные слоты, настроение внутри трека — вне среза.

## Non-goals

- ИИ и автогенерация текста.
- Ручная раскладка слотов и подбор по настроению.
- Лайк как KPI в `catalogStats`.
- Запись склейки в Telegram.
- JWT / tenant / полировка UI.
