## Purpose

Показать лайкнутые случайные склейки трека в меню каталога — живая «История» без ИИ.

## ADDED Requirements

### Requirement: Раздел истории в меню

В боковом меню каталога раздел «История» MUST быть доступен (не заглушка). В нём MUST быть сборка черновика и список сохранённых склеек. Тексты MUST быть по-русски. Раздел MUST NOT предлагать ИИ.

#### Scenario: Открыть историю

- **GIVEN** в меню есть пункт «История»
- **WHEN** его открывают
- **THEN** видны кнопка «Собрать» (или эквивалент) и список лайкнутых склеек (или пустое состояние)

### Requirement: Список сохранённых склеек

Список MUST показывать сохранённые склейки от новых к старым: дата и содержимое слотов (роль + текст фразы, либо «нет кусков»). Пустой список MUST показывать понятное пустое состояние, без ошибки.

#### Scenario: После лайка

- **GIVEN** автор лайкнул черновик
- **WHEN** смотрят историю
- **THEN** сверху списка видна эта склейка с датой и текстами слотов

#### Scenario: Пустая история

- **GIVEN** лайкнутых склеек нет
- **WHEN** открывают историю
- **THEN** показано пустое состояние по-русски
