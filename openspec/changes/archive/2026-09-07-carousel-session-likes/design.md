## Context

Карусель — `LyricList` → `Viewport`: фразы режутся по `\n` в слайды (`createCarouselList`). Очередь и история снимков уже есть (`carousel-queue` / `carousel-history`). Сейчас `saveCarouselHistory` с клиента пишет только `QUEUE` при очистке. Enum `SHUFFLE` в схеме есть, но новые снимки шаффла не пишутся. Жесты списка истории (свайп влево → корзина) — образец для оси жеста на карусели. См. proposal.md.

## Goals / Non-Goals

**Goals:**

- Сессия лайков в памяти (упорядоченные `Lyrics.id`).
- Свайп влево на слайде; метка на следующих строках того же id.
- «Стоп» → обзор → сохранить как `CarouselHistory` с `SHUFFLE` или пометить `isUsed`.
- Подсветка `isUsed` без скрытия с карусели.

**Non-Goals:**

- Склейка в папку / glue.
- Писать показ/скип.
- Смешивать с избранным.
- Фильтр полки «использованные» в этом change (флаг есть, фильтр по умолчанию не сужает).

## Decisions

### 1. Сессия лайков рядом с очередью

Расширить `CarouselSessionProvider`: `likedIds: number[]` (порядок первого свайпа), `toggleLike`, `clearLikes`, `removeLike`. Решафл / очистка очереди MUST NOT обязательно чистить лайки сессии (лайки живут до Стоп→сохранить или явного сброса при сохранении). Снимок истории — только id из `likedIds`, не текущая очередь и не весь шаффл каталога.

Альтернатива: отдельный провайдер — лишний слой для одного списка.

### 2. Свайп на Viewport

В `viewport.tsx` распознать горизонталь после порога (как `useHistoryRowGestures`: pending → x|y). Вертикаль — скраб; горизонталь влево на hit слайда — toggle like по `data-catalog-id`. Караоке MUST NOT останавливаться от лайка. Короткий flash сердца на слайде, без toast. Повторный свайп по тому же сообщению снимает лайк.

### 3. Стоп = оверлей, не меню

Кнопка chrome рядом с историей: бейдж числа лайков. Оверлей (dialog/sheet) со списком превью из текущего `lyrics` / кэша id→текст. Действия: снять, открыть `MessageDeskDialog`, «Сохранить в историю», «Использовал» на строку или на весь список. После успешного save — `clearLikes`.

### 4. Источник SHUFFLE

`saveCarouselHistory(lyricIds, SHUFFLE)`. Не писать весь шаффл каталога. Кольцо 12 и лайк снимка без изменений. Запуск из истории — `loadQueue` как сейчас.

### 5. isUsed — полка-подсветка

Prisma `isUsed Boolean @default(false)`; seed не трогает. GraphQL на `Lyric` и в `updateLyricFlags`. Обычный список карусели не исключает `isUsed`. UI: оттенок/бейдж на слайде и в списках; кнопка на карточке. Не смешивать с `isHidden` / «Готово».

## Risks / Trade-offs

- [Свайп vs скраб] → ось pending и порог; иначе ложные лайки.
- [Текст для списка Стоп] → брать из текущего `sessionLyrics` / слайдов; если id уже ушёл из окна — хранить снимок текста при лайке в сессии.
- [SHUFFLE в UI истории] → иконка источника уже есть; семантика «лайки с карусели», не «весь шаффл».

## Migration Plan

1. Заход 1: только клиент сессии и жеста.
2. Заход 2: migrate `isUsed` + GraphQL + save SHUFFLE + подсветка.
3. Заход 3: карточка и списки меню.
