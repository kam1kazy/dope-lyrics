# carousel-history Specification

## Purpose

Автор хранит короткие снимки своей очереди после очистки и снимки лайкнутых с карусели, открывает их из меню или с главной кнопки, лайкает как склейки генератора и запускает снова.

## Requirements

### Requirement: Снимок из сессии лайков

Система MUST дать сохранить упорядоченный список id из сессии лайков карусели в историю с источником `SHUFFLE`. Этот снимок MUST NOT быть полным шаффлом каталога. «Перемешать заново» MUST NOT писать снимок. Кольцо 12 и лайк снимка MUST работать как для снимков очереди.

#### Scenario: Сохранить лайки с карусели

- **GIVEN** в сессии лайков три фразы
- **WHEN** автор в «Стоп» нажимает сохранить в историю
- **THEN** в истории есть снимок с этими тремя id в том же порядке и источником `SHUFFLE`

#### Scenario: Решафл не пишет лайки

- **GIVEN** в сессии лайков есть фразы
- **WHEN** автор нажимает «Перемешать заново»
- **THEN** новая запись в истории не появляется из-за решафла
