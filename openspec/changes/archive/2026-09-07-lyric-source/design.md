## Context

`lyric_id` сейчас = Telegram `message_id`. Импорт Apple Notes с номерами 1–685 без отдельного источника ломает дедуп ingest: старые TG-сообщения с теми же id пропускаются.

## Decisions

1. **Enum `LyricSource` на `Lyrics`**, default `TELEGRAM`. Существующие строки получают его миграцией.
2. **Дедуп** `loadNewRecords` только среди `source = TELEGRAM`. Apple Notes идемпотентны по `(APPLE_NOTES, lyric_id)`.
3. **Фильтр `sources`** только в меню → Список. Карусель не передаёт аргумент → все источники в ленте.
4. **Пометка** — подпись на табе «Профиль» карточки, не хештег; карусель и строка списка без пометки.
5. **Разрез/нарезка** копируют `source`. Склейка (`lyric_id: 0`) — `TELEGRAM`.
6. **Дата импорта Apple Notes** — mtime файла (экспорт без дат создания).

## Risks

- Совпадение `lyric_id` между источниками ожидаемо; уникальность только в паре с `source`.
- Повторный импорт той же папки безопасен (skip).
