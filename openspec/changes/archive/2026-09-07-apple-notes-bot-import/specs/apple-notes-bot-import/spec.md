## Requirements

### Requirement: Импорт Apple Notes через бота

Система MUST позволить админу (`BOT_ADMIN_ID`) командой `/notes` открыть меню импорта Apple Notes. Команда MUST быть в Bot Commands (`setMyCommands`). Путь папки Notes MUST храниться для админа (по умолчанию `Музыка/Рэпчик`, сегменты через `/`).

Меню MUST содержать кнопки: **FAQ**, **Настройки**, **Скрипт**, **Загрузить**.

- **FAQ** MUST прислать краткую инструкцию по-русски.
- **Настройки** MUST ждать текстовый путь папки Notes; кнопка **Отмена** (и `/notes cancel`) MUST сбрасывать ожидание.
- **Скрипт** MUST выдать `.applescript` под текущий путь. Скрипт MUST писать `.txt` с YAML `created`/`modified` в `Desktop/Dope Notes Export/`.
- **Загрузить** MUST открыть окно ожидания zip (~30 мин); кнопка **Отмена** (и `/notes cancel`) MUST сбрасывать ожидание.

Получив zip от админа в окне ожидания, система MUST распаковать `.txt` (`fflate`), импортировать как `source = APPLE_NOTES` с датами из YAML (тот же модуль, что CLI), ответить счётчиками по-русски. Не-админ MUST NOT запускать импорт. Повторный тот же набор MUST NOT плодить дубликаты по существующим правилам дедупа.

#### Scenario: Меню /notes

- **GIVEN** админ пишет `/notes`
- **WHEN** бот отвечает
- **THEN** приходит меню с кнопками FAQ, Настройки, Скрипт, Загрузить и текущим путём Notes

#### Scenario: Выдача скрипта

- **GIVEN** админ в меню нажимает «Скрипт»
- **WHEN** бот отвечает
- **THEN** приходит файл `.applescript` под сохранённый путь и краткая подпись без обязательной строки `osascript`

#### Scenario: Импорт zip

- **GIVEN** админ нажал «Загрузить» и присылает zip с заметками
- **WHEN** бот обрабатывает документ
- **THEN** в каталоге появляются/обновляются записи `APPLE_NOTES`, в ответе есть числа загруженных и обновлённых дат

#### Scenario: Отмена кнопкой

- **GIVEN** админ ждёт путь или zip
- **WHEN** нажимает «Отмена»
- **THEN** последующий текст/zip не обрабатывается как часть этого ожидания
