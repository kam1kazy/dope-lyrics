## Why

Автор играет с генератором, и обычно в ответе ИИ хороши почти все строки, кроме двух-трёх. Сейчас поправить их можно только через «Ещё раз» — и тогда модель переписывает весь трек и теряет удачный куплет. Нужен точечный путь: автор показывает, какие строки переделать, а какие не трогать, и модель меняет только отмеченное.

## What Changes

- В ответе ИИ под склейкой строку можно пометить кликом. Клик крутит метку **одной** строки по кругу: красная (переделать) → зелёная (нравится, оставить) → без метки. Соседние строки клик не трогает. Метки частей в квадратных скобках не метятся.
- Кнопка «Ещё раз» у ответа заменяется на «Внести правки». Она активна, когда есть хотя бы одна красная строка. Полностью новый вариант по-прежнему даёт «Поправить ИИ» над ответом. **BREAKING** для привычки: у ответа больше нет «Ещё раз».
- «Внести правки» отправляет модели ответ с пометками. Красные строки модель переписывает, каждую в одну строку. Зелёные и неотмеченные остаются буква в букву — это гарантирует сервер, а не только просьба к модели.
- После ответа красные метки снимаются, зелёные остаются на своих строках.
- «Было / стало» по блоку переезжает с одинарного клика на зажатие. Меню блока («вернуть оригинал / свой вариант / поправить») убирается: клик теперь — пометка. Свою правку строк автор делает уже в сохранённом тексте.
- Запрос «Внести правки» учитывается в расходе отдельным видом «Правка по пометкам».

## Non-goals

- Пометки в сохранённом тексте («Тексты»): там правит только автор, ИИ не вызывается.
- Шов жёлтый/зелёный: он показывает, откуда слово, пометки — что сделать со строкой. Цвета и смысл не смешиваем.
- Предразметка строк моделью-критиком, пары правок «ИИ → автор», автокритик — отложены далеко ([roadmap E](../../../docs/roadmap.md)).
- Несколько вариантов на одну красную строку, выбор из вариантов.
- Перестановка строк, перенос находки в другую часть, добавление и удаление строк при «Внести правки».
- Свой текст строки прямо в ответе (прежнее «свой вариант»).
- Изменение рамки «Поправить ИИ» 2.0.0 и отбора приёмов.

## Capabilities

### New Capabilities

_нет_

### Modified Capabilities

- `ai-collage-rewrite`: «Ещё раз» заменяется на «Внести правки»; добавляются пометки строк в ответе, правка только красных строк с гарантией неизменности остальных, «было / стало» по зажатию, учёт запроса отдельным видом.

## Impact

- Клиент: `client/src/shared/ui/before-after-text/` (клик → метка, зажатие → было / стало, без меню блока), `client/src/features/catalog-assemble/ui/collage-rewrite-panel.tsx` (кнопка «Внести правки», состояние меток), запрос GraphQL.
- Сервер: новая мутация GraphQL правки по пометкам; модуль `server/src/modules/ai/line-marks/` (рамка, запрос, сервис) рядом с `rewrite/`, вызов через `callModel`.
- Prisma: значение `LINE_MARKS` в `AiUsageKind` — миграция; подпись вида в «Последних запросах».
- Тесты: сборка ответа из пометок (неотмеченные и зелёные строки не меняются), разбор ответа модели, цикл метки на клиенте.
