## Context

Генератор (`client/src/features/catalog-assemble/`, `server/src/modules/lyrics/track-assemble.ts`) собирает склейку `slots: [{ songRole, parts: [{ lyricId, startLine, endLine }] }]` по форме и `LyricPoolFilter`. Лайкнутая склейка уходит в `LyricCollage` (`likeCollage`). В меню (`client/src/widgets/catalog-menu/ui/catalog-menu.tsx`) уже стоят заглушки `references` и `ai-settings` с `disabled: true`.

Эталон сейчас — флаг `Lyrics.isReference` (ADR 0006). Права — `can()` в `server/src/modules/auth/permissions.ts`, каталог изолирован по `userId`.

Эталон AI-обвязки — youways (`server/src/modules/ai/`): провайдер polza через `/chat/completions`, `usage.prompt_tokens / completion_tokens`, цена считается из env-цен за 1M токенов. Берём принципы и маленький кусок провайдера, не модуль целиком.

Telegram не участвует: только GraphQL.

## Goals / Non-Goals

**Goals:**

- Один вызов модели на «Поправить ИИ», синхронно в mutation.
- След по каждому вызову: модель, версия промпта, токены, рубли, длительность, статус.
- Текст из генератора с тремя неизменяемыми снимками и рабочей версией.

**Non-Goals:**

- Общий AI-фреймворк, реестр промптов, `AiArtifact`-подобная таблица на все случаи. Под каждый новый вид вывода таблицу заводим, когда он появится.
- Очередь и фоновые задачи.

## Decisions

### 1. Промпт автора и рамка в коде — разные вещи

В модель уходят два слоя system:

```
[рамка — в коде, версия RAMKA_VERSION]
  формат ответа: только текст трека, без пояснений, по-русски;
  структура: метки частей как в склейке; оригинал — материал, его можно переписать
[промпт автора — из AiPrompt, текущая версия]
  голос, вайб, правила автора
```

User-сообщение: тема трека (если есть), склейка по частям, затем блок «как я пишу» — примеры.

**Почему:** автор может написать в поле что угодно, и формат ответа не должен от этого ломаться. Рамку меняет разработчик, промпт — автор. В `AiUsage` пишутся обе версии.

**Альтернатива:** весь промпт в поле настроек. Отклонено: стирание одной строки ломает парсинг ответа.

### 2. Примеры стиля — без embeddings

Сервер добирает до `AI_STYLE_EXAMPLES` (по умолчанию 60) фраз автора:

1. все `isReference` (до половины лимита, свежие первыми);
2. остальное — случайно из пула по тому же `LyricPoolFilter`, что у склейки, без фраз, которые уже в склейке.

Текст чистится тем же `stripGeneratorMarks`. Фразу длиннее 8 строк режем до первых 8.

**Почему:** при ~3k фраз и готовой разметке фильтр генератора уже даёт «похожее по вайбу». Embeddings — когда станет видно, что выборка не про то.

### 3. Хранение

```prisma
model AiPrompt {          // каждая правка — новая строка, текущая = последняя
  id, userId, text, createdAt
}

model AiUsage {
  id, userId, kind (enum AiUsageKind: COLLAGE_REWRITE),
  model, promptId?, frameVersion, tokensIn, tokensOut,
  costRub Decimal?, latencyMs, status (enum: OK | ERROR), error?, createdAt
}

model TrackText {
  id, userId, theme?, slots Json,         // какие фразы взяли (shape LyricCollage)
  sourceText, aiText,                     // снимки 1 и 2, после создания не меняются
  text,                                   // рабочая версия
  finalText?, doneAt?,                    // снимок 3 по «Готово»
  promptId?, usageId?, createdAt, updatedAt
}
```

`AiUsage` пишется и на ошибку (без токенов) — видно, что провайдер падал.

Статус текста отдельным полем не храним: `doneAt != null` значит «готово». Повторное «Готово» перезаписывает `finalText` и `doneAt` — финал тот, что нажат последним.

**Почему не `LyricCollage`:** у склейки нет текста, только ссылки; правки фраз в каталоге меняли бы старые тексты. Снимок — строка, она не зависит от каталога.

**Почему не новые `Lyrics`:** тексты не должны попадать в карусель, сводку и фильтры. Отдельная таблица убирает их оттуда без единого `where`.

### 4. Поток «Поправить» → «Сохранить»

```
клиент: склейка + тема
   │  mutation rewriteCollage(slots, theme, filter, hideAdlibs)
   ▼
сервер: can(OWNER) → ключ есть? → собрать sourceText из slots
        → примеры → polza → AiUsage
   ◀── { sourceText, aiText, usageId }
клиент: показывает ответ, можно «Ещё раз» (новый вызов) или «Сохранить»
   │  mutation createTrackText(slots, theme, aiText, usageId, hideAdlibs)
   ▼
сервер: TrackText.text = aiText
```

Ответ модели до сохранения в базе не лежит, кроме учёта в `AiUsage`. Несохранённое «Ещё раз» не копит мусор.

`sourceText` на сохранении сервер **пересобирает** из `slots`, а не берёт с клиента. `aiText` берётся с клиента: сервер его не хранил. Это текст самого автора, подделывать его некому.

### 5. Провайдер

`server/src/modules/ai/polza.client.ts` — одна функция `complete({ system, user, maxTokens }) → { text, tokensIn, tokensOut, model }` на `fetch` с `AbortSignal.timeout(AI_TIMEOUT_MS)`. Без стриминга, без интерфейса провайдеров. Будет второй провайдер — тогда и интерфейс.

Env в `server/src/config/env.ts` (`httpEnvSchema`), все с дефолтами, процесс без них не падает:

`AI_BASE_URL`, `AI_API_KEY` (пусто = ИИ выключен), `AI_MODEL`, `AI_TIMEOUT_MS` (60000), `AI_MAX_TOKENS` (2048), `AI_STYLE_EXAMPLES` (60), `AI_COST_RUB_PER_1M_IN`, `AI_COST_RUB_PER_1M_OUT` (0 = цену не считаем, `costRub = null`).

### 6. Доступ

Новое действие `ai:use` в `permissions.ts`, только `OWNER`. Все AI-query и mutation и разделы проверяют его. `TrackText`, `AiPrompt` и `AiUsage` фильтруются по `userId`, как каталог.

**Почему не ADMIN:** платит автор; ADMIN может звать людей по приглашениям. Расширить — одна строка.

### 7. Шов

На клиенте пословное сравнение (`diff`, `diffWordsWithSpace`):

- жёлтый: слова `aiText`, которых нет в `sourceText`;
- зелёный: слова `finalText` (или `text`, пока не «Готово»), которых нет в `aiText`.

Показ финала: берём финал и красим каждое слово по тому, откуда оно пришло. Переключатель «Шов» выключает подсветку и запоминается в `localStorage`. Вкладки «Из моих / ИИ / Финал» показывают снимки как есть.

**Альтернатива:** считать diff на сервере. Отклонено: это чистое отображение, на сервере не нужно.

### 8. UI

- Генератор: под склейкой поле «Тема трека» и кнопка «Поправить ИИ» (только у `OWNER`; без ключа — неактивна с подписью «ИИ не настроен»). Ответ — панелью под склейкой с «Ещё раз» и «Сохранить».
- Шапка генератора: рядом с историей — кнопка «Тексты»: список (дата, тема, «готово»), клик открывает текст.
- Текст: редактор `text` (textarea, сохранение по кнопке), вкладки снимков, шов, «Готово».
- «Настройки ИИ»: снять `disabled` в меню. Внутри: промпт (textarea + «Сохранить», ниже список прошлых версий с датой, клик показывает текст), расход (за сегодня / 30 дней / всё время: запросы, токены, ₽), последние 20 запросов.

Новые фичи: `client/src/features/ai-settings/`, `client/src/features/track-texts/`. Кнопка правки — внутри `catalog-assemble`.

## Risks / Trade-offs

- **[Модель пишет «ChatGPT-рэп»]** → примеры стиля и промпт автора. Модель — env, меняется без кода. Проверка — руками на стенде, первые тексты.
- **[Ответ 20–60 с в обычной mutation]** → таймаут 60 с, кнопка блокируется со спиннером. В `nginx.prod.conf` у `/essence/graphql` уже `proxy_read_timeout 120s` — запас есть.
- **[Модель вернула пояснения вместо текста]** → рамка запрещает; срезаем обрамление вида ```` ``` ```` и «Вот текст:». Пустой ответ — ошибка по-русски.
- **[Цена неточная]** → `costRub` — оценка по env-ценам, как в youways. Счёт polza — источник правды.
- **[Склейка пуста или из одной фразы]** → кнопка неактивна, пока в склейке нет хотя бы одного непустого слота.

## Migration Plan

1. Миграция Prisma добавляет три таблицы и enum'ы, старые данные не трогает.
2. На проде до выкатки задать `AI_API_KEY`, `AI_MODEL`, `AI_BASE_URL`, цены. Без них выкатка безопасна: ИИ просто выключен.
3. Откат: ключ пустой — ИИ выключен; таблицы можно оставить.
