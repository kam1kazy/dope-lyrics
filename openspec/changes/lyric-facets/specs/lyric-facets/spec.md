## Purpose

Автор размечает фразу четырьмя необязательными гранями (настроение, подача, роль, готовность), чтобы фильтровать каталог и копить корпус без модели.

## ADDED Requirements

### Requirement: Профиль хранит четыре грани

Система MUST хранить у записи каталога готовность и необязательные настроение/подачу без роли, плюс независимый набор настроения и подачи **для каждой включённой роли в песне**. Фраза MAY иметь несколько ролей сразу: клик по роли включает её и открывает её набор, двойной клик снимает роль. Клик по чипу настроения, подачи, роли или готовности MUST выбирать значение; повторный клик MUST NOT снимать его; двойной клик MUST отключать параметр. Словари MUST быть:

- настроение: агрессия, тоска, ирония, нежность, бравада, тревога, холод, эйфория;
- подача: панч, флоу, хук, spoken, напев, адлиб, скороговорка;
- роль: куплет, хук, бридж, интро, сцена, панчлайн, скетч;
- готовность: строка, фрагмент, блок, текст, готово.

Загрузка истории из Telegram и повторный seed MUST NOT заполнять настроение, подачу и роль и MUST NOT сбрасывать уже заданный профиль. При **новой** вставке система MUST выставить готовность по числу непустых строк текста (абзац = 4 строки, floor): 1–3 → строка, 4–19 → фрагмент, 20–35 → блок, 36+ → текст; пустой текст → готовность пустая. Значение «готово» MUST NOT ставиться формулой.

#### Scenario: Новая фраза из чата

- **GIVEN** сообщение с несколькими непустыми строками попало в каталог из Telegram впервые
- **WHEN** его открывают в карточке
- **THEN** настроение, подача и роль пустые, готовность соответствует длине текста

#### Scenario: Seed не затирает разметку

- **GIVEN** у фразы уже выбраны настроение, подача или готовность «готово»
- **WHEN** снова сеют или парсят тот же чат
- **THEN** выбранные грани остаются

#### Scenario: Backfill только пустой готовности

- **GIVEN** у части фраз готовность пустая, у части уже задана
- **WHEN** применяют data-миграцию по длине
- **THEN** пустые получают строка/фрагмент/блок/текст по правилу, уже заданные не меняются

### Requirement: Таб профиля в карточке сообщения

Карточка сообщения MUST показывать рядом с текстом таб «Профиль». В табе автор MUST мочь выбрать значение грани, снять выбор (снова пусто) и сохранить. Значение вне словаря система MUST отклонить. Ошибки MUST быть по-русски. Кнопки полок (скрыть, избранное, эталон) MUST остаться доступны.

#### Scenario: Сохранить настроение

- **GIVEN** открыта карточка сообщения, таб «Профиль»
- **WHEN** автор выбирает настроение «тоска» и сохраняет
- **THEN** при следующем открытии той же карточки настроение содержит «тоска»

#### Scenario: Снять грань

- **GIVEN** у фразы задана подача «панч»
- **WHEN** автор снимает подачу и сохраняет
- **THEN** подача снова пустая, остальные грани не меняются

#### Scenario: Два настроения на фразе

- **GIVEN** открыта карточка, таб «Профиль»
- **WHEN** автор выбирает настроение «тоска» и «ирония» и сохраняет
- **THEN** при следующем открытии оба значения на месте

#### Scenario: Неверное значение

- **WHEN** клиент или запрос передаёт настроение не из словаря
- **THEN** профиль не меняется и показывается ошибка по-русски

### Requirement: Фильтр карусели по граням

Список фраз MUST принимать необязательный фильтр по каждой грани. Несколько разных граней MUST сочетаться как логическое И. Несколько значений настроения или подачи в одном фильтре MUST сочетаться как логическое ИЛИ: фраза проходит, если пересекается хотя бы с одним выбранным значением. Пустой фильтр по грани MUST не сужать список. Фраза с пустой гранью MUST не попадать в выборку, если эта грань в фильтре задана.

#### Scenario: Карусель только панчи

- **GIVEN** в каталоге есть фразы с подачей «панч» и без подачи
- **WHEN** включают фильтр подача = панч
- **THEN** в списке только фразы с подачей «панч»

#### Scenario: Две грани сразу

- **GIVEN** фильтр настроение = агрессия и роль = хук
- **WHEN** запрашивают список
- **THEN** остаются только фразы, у которых оба значения совпадают

#### Scenario: Несколько настроений в фильтре

- **GIVEN** фильтр настроение = тоска и агрессия
- **WHEN** запрашивают список
- **THEN** остаются фразы, у которых есть хотя бы одно из этих настроений
