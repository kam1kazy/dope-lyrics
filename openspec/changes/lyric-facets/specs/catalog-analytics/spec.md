## Purpose

Показать состав каталога детерминированными счётчиками: покрытие профиля, разложение по граням и полки эталон / избранное / скрыто — без модели и без режима склейки трека.

## ADDED Requirements

### Requirement: Сводка корпуса

Система MUST отдать сводку по всему каталогу (без применения фильтров карусели): общее число фраз; число и доля эталонов (`isReference`); число и доля избранного (`isFavorite`); число и долю скрытых; число и долю фраз, у которых заполнена хотя бы одна грань профиля; для каждой грани — число фраз с непустым значением и разложение по значениям словаря (включая нули, если значения нет ни у кого).

Доли MUST считаться от общего числа фраз. При пустом каталоге счётчики MUST быть нули, доли MUST не показывать деление на ноль как ошибку.

#### Scenario: Каталог с полками и дырами профиля

- **GIVEN** 10 фраз: 2 эталона, 3 в избранном, 1 скрытая, у 4 заполнена хотя бы одна грань
- **WHEN** открывают сводку каталога
- **THEN** видны 10 / 2 эталона / 3 избранных / 1 скрытая / 4 с профилем и соответствующие доли

#### Scenario: Пустой каталог

- **GIVEN** в базе нет фраз
- **WHEN** запрашивают сводку
- **THEN** все числа 0, интерфейс не падает

### Requirement: Разложение по словарю

Для настроения, подачи, роли и готовности сводка MUST показать, сколько фраз имеет каждое значение словаря. Фразы с пустой гранью MUST учитываться отдельно как «без значения», не размазываясь по словарю.

#### Scenario: Две тоски и пустые

- **GIVEN** 5 фраз, у двух настроение «тоска», у остальных настроение пустое
- **WHEN** смотрят разложение настроения
- **THEN** тоска = 2, остальные значения словаря = 0, без значения = 3

### Requirement: Полки на карточке не дублируют историю

На карточке сообщения статус эталона и избранного MUST совпадать с текущими булевыми флагами. Система MUST NOT вести счётчик «сколько раз ставили эталон» и MUST NOT показывать частоту попаданий в эталоны для одной фразы.

#### Scenario: Эталон включён

- **GIVEN** фраза с `isReference = true` и `isFavorite = false`
- **WHEN** открывают карточку
- **THEN** видно, что это эталон и что её нет в избранном, без числа переключений

### Requirement: Раздел сводки в каталоге

В боковом меню каталога MUST быть доступный раздел со сводкой (не заглушка). Тексты MUST быть по-русски. Сводка MUST не требовать ИИ и MUST не предлагать собрать трек.

#### Scenario: Открыть сводку из меню

- **GIVEN** в меню каталога есть раздел сводки
- **WHEN** его открывают
- **THEN** видны числа покрытия, полок и разложение по граням из текущей базы
