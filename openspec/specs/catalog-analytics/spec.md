# catalog-analytics Specification

## Purpose

Показать состав каталога детерминированными счётчиками по **кускам песни** (роль + настроение/подача внутри роли) и полкам, включая цензуру — без модели и без UI конструктора. Те же корзины позже станут выборкой сборки трека.

## Requirements

### Requirement: Сводка корпуса и полок

Система MUST отдать сводку по всему каталогу (без фильтров карусели): общее число фраз; число и долю эталонов; избранного; скрытых; **цензурных**; число и долю фраз, у которых включена хотя бы одна роль.

Доли MUST считаться от общего числа фраз. При пустом каталоге счётчики MUST быть нули, доли MUST не показывать деление на ноль как ошибку.

#### Scenario: Каталог с полками и ролями

- **GIVEN** 10 фраз: 2 эталона, 3 в избранном, 1 скрытая, 1 цензурная, у 4 включена хотя бы одна роль
- **WHEN** открывают сводку каталога
- **THEN** видны 10 / 2 эталона / 3 избранных / 1 скрытая / 1 цензурная / 4 с ролью и соответствующие доли

#### Scenario: Пустой каталог

- **GIVEN** в базе нет фраз
- **WHEN** запрашивают сводку
- **THEN** все числа 0, интерфейс не падает

### Requirement: Разложение по ролям, не по плоским граням

Для каждой роли словаря сводка MUST показать, сколько **фраз** имеют эту роль (фраза с куплетом и хуком входит в оба ряда). На экране дашборда ряд роли MUST быть именем и счётчиком; вложенное разложение настроения и подачи **внутри роли** MAY оставаться в ответе API, но MUST NOT дублироваться под каждой ролью на дашборде (глобальный топ и блок «без роли» покрывают грани).

Глобальный COUNT уникальных фраз «с тоской где угодно» для главной цифры сводки MUST идти отдельным топом граней, а не заменять ряды ролей. Набор настроения/подачи без роли MUST быть отдельной строкой «без роли», не смешиваясь с ролями.

Готовность MUST раскладываться по фразам (одно значение на фразу), с рядом «без значения», и на экране MUST показываться воронкой (полосы по словарю строка → готово).

#### Scenario: Один текст — куплет и хук

- **GIVEN** одна фраза с ролями куплет (тоска) и хук (бравада)
- **WHEN** смотрят разложение ролей на дашборде
- **THEN** куплет = 1, хук = 1; под ролями нет отдельных строк «тоска» / «бравада»

#### Scenario: Тоска только без роли

- **GIVEN** фраза с тоской в наборе без роли и без ролей
- **WHEN** смотрят разложение
- **THEN** ряды ролей по тоске не растут; строка «без роли» показывает тоску = 1

### Requirement: Полки на карточке не дублируют историю

На карточке сообщения статус эталона, избранного, скрыто и цензуры MUST совпадать с текущими булевыми флагами. Система MUST NOT вести счётчик «сколько раз ставили эталон».

#### Scenario: Эталон включён

- **GIVEN** фраза с `isReference = true` и `isFavorite = false`
- **WHEN** открывают карточку
- **THEN** видно, что это эталон и что её нет в избранном, без числа переключений

### Requirement: Раздел сводки в каталоге

В боковом меню каталога MUST быть доступный раздел со сводкой (не заглушка). Тексты MUST быть по-русски. Сводка MUST не требовать ИИ и MUST NOT запускать сборку трека, но цифры MUST быть теми же корзинами, из которых конструктор берёт куски. Экран MUST быть дашбордом (карточки, график активности, топ граней, воронка готовности), а не плоским списком чисел без визуализации.

#### Scenario: Открыть сводку из меню

- **GIVEN** в меню каталога есть раздел сводки
- **WHEN** его открывают
- **THEN** видны полки включая цензуру и доноров, покрытие по ролям, топ настроения/подачи, воронка готовности и график активности из текущей базы

### Requirement: Разложение по энергии

Сводка каталога MUST раскладывать энергию по фразам (одно значение на фразу), включая все значения словаря и ряд «без значения». Энергия MUST NOT входить в «топ тем» рядом с настроением и подачей.

#### Scenario: Сводка с энергией

- **GIVEN** две фразы с энергией «громко», одна с «шёпот», одна без энергии
- **WHEN** открывают сводку
- **THEN** громко = 2, шёпот = 1, без значения = 1, остальные ступени словаря = 0

#### Scenario: Пустой каталог по энергии

- **GIVEN** в базе нет фраз
- **WHEN** запрашивают сводку
- **THEN** счётчики энергии нули, интерфейс не падает

### Requirement: Дашборд сводки

Раздел «Сводка» в меню каталога MUST показать дашборд по всему корпусу (без фильтров карусели): крупное число фраз и прирост за последние 30 дней по `Lyrics.date`; полки (эталоны, избранное, скрыто, цензура, доноры) и покрытие «с ролью»; список ролей только с именем и числом фраз (без вложенного разложения настроения/подачи под каждой ролью); топ настроения и подачи по всему каталогу; воронку готовности (строка → готово); блок «без роли» с набором настроения/подачи; короткий текст о числе фраз со статусом «готово». Тексты MUST быть по-русски. Сводка MUST NOT требовать ИИ и MUST NOT запускать сборку трека.

#### Scenario: Открыть дашборд

- **GIVEN** в меню каталога есть раздел сводки и в базе есть фразы
- **WHEN** его открывают
- **THEN** видны число фраз, прирост за месяц, полки, роли со счётчиками, топ граней, воронка готовности и блок «без роли»

#### Scenario: Пустой каталог

- **GIVEN** в базе нет фраз
- **WHEN** открывают сводку
- **THEN** все числа 0, график и списки не падают

### Requirement: Активность фраз по дням

Система MUST отдать ряд активности по дате фразы (`Lyrics.date`) за выбранный период 7, 30 или 90 дней. Период MUST влиять только на график, не на остальные цифры сводки. Ряд MUST включать каждый календарный день диапазона в UTC, в том числе дни с нулём. Подписи оси на экране MUST быть по-русски (день и сокращённый месяц).

#### Scenario: Смена периода графика

- **GIVEN** открыта сводка с графиком за 30 дней
- **WHEN** выбирают 7 дней
- **THEN** обновляется только график активности; число фраз и полки не меняются

#### Scenario: Дни без фраз

- **GIVEN** в выбранном периоде есть дни без новых фраз
- **WHEN** запрашивают активность
- **THEN** эти дни присутствуют в ряде со счётчиком 0

### Requirement: Глобальный топ настроения и подачи

Сводка MUST отдать счётчики по каждому значению словарей настроения и подачи. Фраза MUST увеличить счётчик значения не больше одного раза, если это значение есть в любом слоте `roleProfiles` или в корневом наборе без роли. Хештеги Telegram MUST NOT входить в этот топ. На экране MUST показывать только значения с count > 0, отсортированные по убыванию, с полосой относительно максимума в топе.

#### Scenario: Одна фраза — тоска в роли и панч без роли

- **GIVEN** фраза с ролью куплет (тоска) и корневой подачей панч
- **WHEN** смотрят топ тем
- **THEN** тоска = 1 и панч = 1; повтор того же значения на той же фразе не удваивает счётчик

#### Scenario: Нулевые грани скрыты

- **GIVEN** в каталоге нет фраз с «эйфорией»
- **WHEN** смотрят топ тем на экране
- **THEN** «эйфория» не показана в списке
