# lyric-card-slice Specification

## Purpose

Автор выделяет фрагмент фразы двумя чертами, набирает куски списком в карточке и сохраняет их одной новой записью, при желании вырезая взятое из донора.

## Requirements

### Requirement: Вырез диапазона из фразы

Система MUST дать сохранить выделенный диапазон строк как новую запись каталога. Диапазон MUST задаваться двумя стыками строк (`afterLine`, `untilLine`): фрагмент — строки после первой черты до включительно `untilLine`. Новая запись MUST получить тот же Telegram `lyric_id` / `message_id`, те же теги, профиль ролей, полки и дату; медиа и реакции MUST остаться на исходной фразе. Готовность MUST пересчитаться по длине для новой записи и для донора после выреза, если текущее значение не «готово». Система MUST NOT писать результат в Telegram.

Перед записью система MUST спросить «Оставить» или «Вырезать». При «Оставить» исходная фраза MUST не меняться. При «Вырезать» система MUST удалить взятые строки из исходной записи, оставить остаток и включить флаг `isDonor`, если остался непустой текст; если забрали все непустые строки — MUST только скрыть исходную (`isHidden`) и MUST NOT ставить `isDonor`. Ошибки MUST быть по-русски. Пустой фрагмент или пересекающиеся диапазоны MUST отклоняться.

#### Scenario: Вырезать середину

- **GIVEN** фраза из пяти непустых строк
- **WHEN** автор выделяет строки 2–3, подтверждает и выбирает «Вырезать»
- **THEN** в каталоге есть новая запись со строками 2–3, на исходной остались 1, 4, 5, флаг «донор» включён

#### Scenario: Оставить донора

- **GIVEN** выделен фрагмент
- **WHEN** автор выбирает «Оставить»
- **THEN** новая запись создана, исходный текст не изменён, `isDonor` не поставлен

#### Scenario: Забрали всё

- **GIVEN** выделены все непустые строки фразы
- **WHEN** автор выбирает «Вырезать»
- **THEN** новая запись создана, исходная скрыта, текст исходной не переписан, `isDonor` не поставлен

#### Scenario: Пустой фрагмент

- **GIVEN** диапазон оставляет только пустые строки
- **WHEN** автор подтверждает сохранение
- **THEN** каталог не меняется, ошибка по-русски

### Requirement: Вторая черта в режиме разреза

В режиме разреза система MUST показать кнопку «+» слева над ножницами, если в тексте не меньше трёх непустых строк. Нажатие MUST поставить вторую линию ниже первой; повторное нажатие MUST убрать вторую линию. Обе линии MUST прилипать к стыкам строк и MUST NOT пересекаться так, что между ними нет непустого текста. Строки между чертами MUST быть подсвечены. Одна черта и разрез надвое MUST работать как раньше.

#### Scenario: Включить вторую черту

- **GIVEN** режим разреза, фраза из четырёх непустых строк, одна черта
- **WHEN** автор нажимает «+»
- **THEN** появляется вторая черта, зона между ними подсвечена

#### Scenario: Убрать вторую черту

- **GIVEN** две черты активны
- **WHEN** автор нажимает кнопку снятия второй черты
- **THEN** остаётся одна черта, подсветка зоны снимается

#### Scenario: Мало строк для двух черт

- **GIVEN** фраза из двух непустых строк
- **WHEN** автор в режиме разреза
- **THEN** кнопка «+» недоступна или скрыта

### Requirement: Нарезка списком в карточке

При двух чертах подтверждение ножницами MUST добавить текущую зону в список кусков внутри открытой карточки, а не сразу писать в каталог. Взятые в список строки MUST отображаться с пониженной прозрачностью и MUST NOT повторно попадать в новый кусок. Новые куски MUST вставать под предыдущими. Автор MUST мочь убрать кусок из списка; тогда опасити строк снимается. Автор MUST мочь переставить куски перетаскиванием. «Сохранить» MUST быть доступно при непустом списке и MUST создать одну новую запись: тексты кусков в текущем порядке, между кусками пустая строка. Перед записью MUST спросить «Оставить» / «Вырезать» с тем же смыслом, что у выреза одного диапазона. Отмена режима MUST сбросить список без изменений каталога. Карточка после сохранения MUST остаться на исходной фразе.

#### Scenario: Набрать два куска

- **GIVEN** две черты, список пуст
- **WHEN** автор добавляет зону ножницами, выделяет другую зону и добавляет ещё
- **THEN** в списке два куска, взятые строки блеклые

#### Scenario: Переставить и сохранить

- **GIVEN** в списке два куска
- **WHEN** автор меняет их порядок и сохраняет с «Вырезать»
- **THEN** новая запись содержит тексты в новом порядке, на доноре вырезаны оба диапазона

#### Scenario: Убрать кусок из списка

- **GIVEN** кусок в списке
- **WHEN** автор удаляет его крестиком
- **THEN** куска нет в списке, строки снова доступны для выделения

#### Scenario: Отмена с несохранённым списком

- **GIVEN** в списке есть куски
- **WHEN** автор выходит из режима разреза
- **THEN** каталог не меняется, список сброшен

### Requirement: Перекладка склеек после выреза диапазонов

Если из донора вырезаны строки, система MUST переложить куски лайкнутых склеек (`LyricCollage`), ссылавшиеся на эту фразу: остаток — сдвинутые индексы на доноре; взятые диапазоны — на новую запись. Текст слотов истории MUST остаться согласованным с каталогом.

#### Scenario: История после выреза середины

- **GIVEN** лайкнутая склейка берёт строки 0–6 фразы, автор вырезает строки 2–3 в новую запись
- **WHEN** вырез сохранён
- **THEN** в истории остаток на доноре со сдвигом, взятые строки ссылаются на новую запись
