# track-assemble Specification

## Purpose

Случайная склейка фраз каталога в черновик трека по ролям в песне, без модели — и сохранение удачной попытки лайком.

## Requirements

### Requirement: Сборка по фиксированному каркасу

Система MUST собирать черновик трека по каркасу слотов: INTRO, VERSE, HOOK, VERSE, BRIDGE, HOOK (в этом порядке). Для каждого слота MUST выбрать случайную фразу из пула с этой `songRole`. Пул MUST включать скрытые фразы и MUST исключать цензурные. В одном черновике одна и та же фраза MUST NOT повторяться, если в нужных пулах есть другие кандидаты. Если пул роли пуст (или все кандидаты уже заняты), слот MUST остаться пустым с понятной подписью, без ошибки запроса.

#### Scenario: Успешная сборка

- **GIVEN** в каталоге есть фразы для INTRO, VERSE, HOOK и BRIDGE
- **WHEN** автор нажимает «Собрать»
- **THEN** черновик показывает шесть слотов в порядке каркаса с текстами (где пул не пуст)

#### Scenario: Пустой пул роли

- **GIVEN** нет ни одной фразы с ролью INTRO
- **WHEN** собирают трек
- **THEN** слот INTRO помечен как «нет кусков», остальные слоты заполняются

#### Scenario: Без повторов в черновике

- **GIVEN** две фразы с VERSE и достаточно других ролей
- **WHEN** собирают трек (в каркасе два слота VERSE)
- **THEN** в двух слотах VERSE разные фразы

### Requirement: Лайк сохраняет черновик

Система MUST сохранять текущий черновик в базу только по явному лайку. Черновик без лайка MUST NOT попадать в историю. Сохранённая запись MUST хранить порядок слотов, роль каждого слота и ссылку на фразу (или пустой слот).

#### Scenario: Лайк

- **GIVEN** на экране собранный черновик
- **WHEN** автор ставит лайк
- **THEN** запись появляется в истории склеек

#### Scenario: Без лайка

- **GIVEN** автор собрал черновик и закрыл раздел без лайка
- **WHEN** открывают историю
- **THEN** этот черновик в списке отсутствует
