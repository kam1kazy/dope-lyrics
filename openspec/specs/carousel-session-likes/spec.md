# carousel-session-likes Specification

## Purpose

Автор во время чтения карусели лайкает отдельные строки свайпом, останавливает поток кнопкой «Стоп», просматривает список и сохраняет сообщения этих строк в историю или помечает использованными.

## Requirements

### Requirement: Сессия лайков на карусели

Система MUST хранить в сессии карусели упорядоченный список лайкнутых **строк** (запись каталога + индекс строки слайда). Порядок MUST быть порядком первого лайка. Повторный лайк той же строки MUST снять её из списка. Лайк одной строки MUST NOT лайкать остальные строки того же сообщения. Лайк сессии MUST NOT писать в полку избранного (`isFavorite`). Пустой список MUST означать, что сохранять нечего.

#### Scenario: Первый свайп

- **GIVEN** карусель показывает строку сообщения
- **WHEN** автор свайпает этот слайд влево
- **THEN** эта строка есть в сессии лайков первой

#### Scenario: Повтор снимает

- **GIVEN** строка уже в сессии лайков
- **WHEN** автор снова свайпает её влево
- **THEN** этой строки нет в сессии лайков

#### Scenario: Другая строка того же сообщения

- **GIVEN** первая строка сообщения уже лайкнута
- **WHEN** на экране идёт вторая строка того же сообщения
- **THEN** у второй строки нет признака лайка, пока её не свайпнули отдельно

### Requirement: Свайп лайкает строку

Свайп влево MUST лайкать текущий слайд-строку, а не всю запись каталога целиком. Вертикальный жест MUST оставаться скрабом карусели. Лайк MUST NOT ставить карусель на паузу. Система MUST показать короткий визуальный отклик (сердце) без toast.

#### Scenario: Лайк только этой строки

- **GIVEN** сообщение из трёх строк
- **WHEN** автор свайпает вторую строку влево
- **THEN** в сессии лайков только вторая строка

### Requirement: Стоп и обзор

Кнопка «Стоп» MUST быть на chrome рядом с историей и MUST показать число лайкнутых строк; иконка MUST быть сердцем (не стоп/отмена). Нажатие MUST открыть список лайкнутых строк без отдельных карточек-блоков: одна строка за другой, без hover-подсветки строки, справа только кнопка снять лайк (перечёркнутое сердце без текста). Двойной клик по строке MUST открыть карточку сообщения. Пустой список MUST объяснить по-русски, что лайков пока нет. Внизу MUST быть «В историю» и справа от неё «Очистить» (снять все лайки сессии без записи в историю), у обеих — тултипы. Сохранение в историю MUST писать уникальные id сообщений этих строк и MUST NOT помечать их как использованные. Полка «использовал» (`isUsed`) из этого окна MUST NOT предлагаться: черновики в истории ещё могут переиспользовать строки; автопометка — позже, когда текст станет «готово» и в нём есть строки из других сообщений.

#### Scenario: Стоп с лайками

- **GIVEN** в сессии два лайка строк
- **WHEN** автор нажимает «Стоп»
- **THEN** виден список из двух строк в порядке лайков

#### Scenario: Стоп без лайков

- **GIVEN** сессия лайков пуста
- **WHEN** автор открывает «Стоп»
- **THEN** показано пустое состояние по-русски

#### Scenario: Двойной клик открывает карточку

- **GIVEN** в списке лайкнутых есть строка
- **WHEN** автор дважды кликает по ней
- **THEN** открыта карточка сообщения этой строки

### Requirement: Сохранение очищает сессию

После успешной записи списка в историю карусели система MUST очистить сессию лайков. Отмена или ошибка сохранения MUST NOT очищать сессию. Снимок MUST содержать уникальные id сообщений в порядке первого лайка строки из каждого сообщения.

#### Scenario: После сохранения

- **GIVEN** в сессии три лайка строк из двух сообщений
- **WHEN** автор сохраняет в историю успешно
- **THEN** сессия лайков пуста, снимок в истории содержит два id сообщений
