# user-invites Specification

## Purpose
Приглашения закрывают регистрацию: новую учётку в каталоге может завести только тот, кому автор или помощник выдал одноразовую ссылку на бота.

## Requirements

### Requirement: Создание приглашения

Пользователь с правом `users:invite` MUST иметь возможность создать приглашение командой бота. В ответ бот MUST прислать ссылку на бота с кодом приглашения и срок её действия. Код MUST быть случайным и непредсказуемым; система MUST NOT хранить его в открытом виде. Срок действия по умолчанию MUST составлять 7 дней.

Пользователь без права `users:invite` MUST получать отказ по-русски, приглашение MUST NOT создаваться.

#### Scenario: Автор создаёт приглашение

- **GIVEN** автор с ролью `OWNER` пишет боту команду приглашения
- **WHEN** бот отвечает
- **THEN** приходит ссылка на бота с кодом и дата, до которой она действует

#### Scenario: Обычный пользователь не приглашает

- **GIVEN** пользователь с ролью `USER`
- **WHEN** он вызывает команду приглашения
- **THEN** бот отказывает по-русски и приглашение не создаётся

### Requirement: Активация приглашения

Открыв ссылку приглашения, Telegram-аккаунт без учётки MUST получить учётку с ролью `USER` и пустым каталогом, а бот MUST ответить по-русски с кнопкой открыть каталог. Приглашение MUST быть одноразовым: после активации повторное открытие той же ссылки другим аккаунтом MUST отклоняться.

Просроченное, отозванное, уже использованное или неизвестное приглашение MUST отклоняться по-русски без заведения учётки. Если ссылку открыл аккаунт, у которого учётка уже есть, бот MUST сообщить, что доступ уже есть, и приглашение MUST NOT считаться использованным.

#### Scenario: Друг активирует приглашение

- **GIVEN** автор выдал другу действующую ссылку
- **WHEN** друг открывает её в Telegram
- **THEN** у друга появляется учётка `USER` с пустым каталогом, бот присылает кнопку открыть каталог

#### Scenario: Ссылка одноразовая

- **GIVEN** друг уже активировал приглашение
- **WHEN** ту же ссылку открывает другой аккаунт
- **THEN** бот отказывает по-русски и учётка не заводится

#### Scenario: Просроченное приглашение

- **GIVEN** срок действия приглашения истёк
- **WHEN** аккаунт без учётки открывает ссылку
- **THEN** бот отвечает, что приглашение недействительно, и учётка не заводится

#### Scenario: У аккаунта уже есть доступ

- **GIVEN** у аккаунта уже есть учётка
- **WHEN** он открывает чужую действующую ссылку приглашения
- **THEN** бот сообщает, что доступ уже есть, и приглашение остаётся действующим

### Requirement: Список и отзыв приглашений

Пользователь с правом `users:invite` MUST видеть в боте свои действующие приглашения с датой создания и сроком и MUST иметь возможность отозвать любое из них. Отозванное приглашение MUST сразу перестать работать. Использованные и просроченные приглашения MUST NOT показываться как действующие.

#### Scenario: Отзыв приглашения

- **GIVEN** автор создал приглашение и ещё никто его не активировал
- **WHEN** автор отзывает его из списка
- **THEN** ссылка перестаёт работать, а приглашение пропадает из действующих

#### Scenario: Список без использованных

- **GIVEN** одно приглашение автора уже активировано, второе ещё нет
- **WHEN** автор открывает список приглашений
- **THEN** в действующих только второе
