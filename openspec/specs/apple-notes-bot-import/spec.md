## ADDED Requirements

### Requirement: Импорт Apple Notes через бота

Система MUST позволить админу (`BOT_ADMIN_ID`) командой `/notes` получить AppleScript для экспорта папки Notes. Путь папки Notes MUST приниматься как сегменты через `/` (по умолчанию `Музыка/Рэпчик`). Скрипт MUST писать `.txt` с YAML `created`/`modified` в `Desktop/Dope Notes Export/`. После выдачи скрипта система MUST ждать zip от того же админа ограниченное время; `/notes cancel` MUST сбрасывать ожидание.

Получив zip от админа в окне ожидания, система MUST распаковать `.txt`, импортировать как `source = APPLE_NOTES` с датами из YAML (как CLI-импорт), ответить счётчиками новых записей и обновлённых дат по-русски. Не-админ MUST NOT запускать импорт. Повторный тот же набор MUST NOT плодить дубликаты по существующим правилам дедупа.

#### Scenario: Выдача скрипта

- **GIVEN** админ пишет `/notes`
- **WHEN** бот отвечает
- **THEN** приходит файл `.applescript` под папку Музыка/Рэпчик и инструкция про zip

#### Scenario: Импорт zip

- **GIVEN** админ уже вызвал `/notes` и присылает zip с заметками
- **WHEN** бот обрабатывает документ
- **THEN** в каталоге появляются/обновляются записи `APPLE_NOTES`, в ответе есть числа загруженных и обновлённых дат

#### Scenario: Отмена

- **GIVEN** админ ждёт zip
- **WHEN** пишет `/notes cancel`
- **THEN** последующий zip не импортируется как часть этого ожидания
