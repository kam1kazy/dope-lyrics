# ai-settings Specification

## Purpose

Раздел «Настройки ИИ»: автор задаёт свой промпт, видит его прошлые версии, сколько токенов и рублей сжёг и последние запросы к модели.

## Requirements

### Requirement: Доступ к ИИ только у владельца

Действия ИИ (правка склейки, промпт, расход) MUST быть доступны только пользователю с ролью `OWNER`. Для остальных ролей сервер MUST отклонить запрос с ошибкой по-русски, а клиент MUST NOT показывать пункт «Настройки ИИ» и кнопку «Поправить ИИ». Промпт, расход и запросы MUST быть видны только их владельцу.

#### Scenario: Пользователь без роли владельца

- **GIVEN** вошёл пользователь с ролью `USER` или `ADMIN`
- **WHEN** он открывает меню и генератор
- **THEN** пункта «Настройки ИИ» и кнопки «Поправить ИИ» нет

#### Scenario: Прямой запрос без прав

- **GIVEN** пользователь с ролью `ADMIN`
- **WHEN** он вызывает правку склейки через API
- **THEN** сервер отвечает ошибкой по-русски, модель не вызывается

### Requirement: ИИ без ключа выключен

Если ключ провайдера не задан, сервер MUST стартовать как обычно. Раздел «Настройки ИИ» MUST открываться и показывать, что ИИ не настроен. Кнопка «Поправить ИИ» MUST быть неактивной с подписью «ИИ не настроен».

#### Scenario: Пустой ключ

- **GIVEN** на сервере не задан ключ провайдера
- **WHEN** владелец открывает генератор
- **THEN** кнопка «Поправить ИИ» неактивна с подписью «ИИ не настроен», остальной генератор работает

### Requirement: Пункт меню «Настройки ИИ»

Пункт меню «Настройки ИИ» MUST быть активным у владельца и открывать раздел с промптом, расходом и последними запросами.

#### Scenario: Открыть настройки

- **GIVEN** владелец в каталоге
- **WHEN** он выбирает в меню «Настройки ИИ»
- **THEN** открывается раздел с полем промпта, сводкой расхода и списком последних запросов

### Requirement: Промпт с версиями

В разделе MUST быть одно текстовое поле промпта и кнопка «Сохранить». Каждое сохранение MUST создавать новую версию; старые версии MUST NOT меняться и удаляться. Текущей MUST считаться последняя сохранённая версия. Под полем MUST быть список прошлых версий с датой; выбор версии MUST показывать её текст. Пустой промпт MUST быть допустим: тогда модель работает только по рамке. Сохранение текста, равного текущей версии, MUST NOT создавать новую версию.

#### Scenario: Новая версия

- **GIVEN** у владельца сохранён промпт «A»
- **WHEN** он меняет поле на «B» и жмёт «Сохранить»
- **THEN** текущий промпт — «B», в списке версий есть «A» с датой

#### Scenario: Без изменений

- **GIVEN** текущий промпт «A»
- **WHEN** владелец жмёт «Сохранить», не меняя текст
- **THEN** новая версия не появляется

### Requirement: Расход

Раздел MUST показывать число запросов, токены на вход и выход и сумму в рублях за сегодня, за 30 дней и за всё время. Если цена за токены не задана, сумма MUST показываться как «—», а токены MUST считаться как обычно. Сумма MUST быть подписана как оценка.

#### Scenario: Цена не задана

- **GIVEN** на сервере не заданы цены за токены и было 3 запроса
- **WHEN** владелец открывает расход
- **THEN** видно 3 запроса и токены, сумма — «—»

### Requirement: Последние запросы

Раздел MUST показывать последние 20 запросов к модели, новые сверху: дата и время, вид запроса, модель, токены, сумма, длительность, статус. Неудачные запросы MUST быть в списке со статусом ошибки и её текстом по-русски.

#### Scenario: Ошибка провайдера в списке

- **GIVEN** провайдер не ответил на правку склейки
- **WHEN** владелец открывает последние запросы
- **THEN** сверху запись с видом «Правка склейки», статусом ошибки и текстом причины
