# Dope Lyrics

Телеграм бот для систематизации заметок из группы и выдачи по критериям в виде текста, который можно зачитывать на манер караоке в красивом интерфейсе и с гибкими настройками.

# 🌟 stack

`bun.sh`
`elysia.js`
`@elysia/graphql-yoga`
`prisma`
`next.js`
`mtcute`

## 💻  Использование

После установки вы сможете взаимодействовать с вашим `Telegram` ботом и использовать его функции для систематизации записей канала c возможностью выбрать любой текст и читать его на манер караоке в красивом интерфейсе и с гибкими настройками.
