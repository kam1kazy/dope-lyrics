# Dope Lyrics

Телеграм бот для систематизации заметок из группы и выдачи по критериям в виде текста, который можно зачитывать на манер караоке в красивом интерфейсе и с гибкими настройками.

# 🌟 stack

`bun.sh`
`elysia.js`
`@elysia/graphql-yoga`
`prisma`
`next.js`
`mtcute`
