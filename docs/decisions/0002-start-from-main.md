# ADR 0002 — Воскрешаем с main, develop не сливаем

Статус: принято
Дата: 2026-09-02

## Решение

База работы — `origin/main` (`bcba015`).
`origin/develop` считаем отдельной поздней линией (auth, JWT, рефакторинг), не текущим стволом.

## Почему

На develop ~62 коммита после точки, с которой мы читали каркас.
Там недовезённая авторизация и перекладка папок. Это ценный склад, не готовый пол.

Молчальный merge сломает простой план: сначала экран и данные, потом дизайн, потом ИИ.

## Как брать код с develop

Cherry-pick или ручной перенос файла. Не merge всей ветки.
Переход «живём на develop» — отдельное решение автора, с новой сверкой `docs/status.md`.
