# ADR 0001 — Документация вместо Jira

Статус: принято
Дата: 2026-09-02

## Решение

У проекта нет Jira. Бэклог, текущая задача и «зачем мы это делаем» живут в `docs/`.

Спеки фич — в `openspec/`. Имя change: kebab-case, не ключ тикета.

`guide/` остаётся косметикой для GitHub и не является рабочей доской.

## Почему

Один автор. Тикеты ради тикетов только размазывают контекст между чатами.
Новый чат должен понять продукт из `docs/00_vision.md`, а не из истории переписки.
