# ADR 0004 — UI на shadcn, Chakra целиком уходит

Статус: принято
Дата: 2026-09-02

## Решение

Весь Chakra снимаем: не только `@chakra-ui/icons`, а `@chakra-ui/react`, `@chakra-ui/next-js` и связанные emotion, если они больше ни на что не нужны.

Новый интерфейс — **shadcn** (эталон youways). Иконки — Lucide. Kit-файлы shadcn не править.

## Когда

Автор посмотрел живой прототип и перенёс kit **до** фильтров (дорожка C, 2 сентября 2026). Chakra в `client/` больше нет.

## Пока

Не возвращать Chakra. Kit-файлы shadcn не править. Первый срез фильтров — на клиенте (дорожка D). Запрос `tag`/`keyword` в GraphQL ещё не делали.
