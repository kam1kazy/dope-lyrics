# ADR 0004 — UI на shadcn, Chakra целиком уходит

Статус: принято
Дата: 2026-09-02

## Решение

Весь Chakra снимаем: не только `@chakra-ui/icons`, а `@chakra-ui/react`, `@chakra-ui/next-js` и связанные emotion, если они больше ни на что не нужны.

Новый интерфейс — **shadcn** (эталон youways). Иконки — Lucide. Kit-файлы shadcn не править.

## Когда

**Не сейчас.** Сначала оживить контур (дорожка A), открыть текущий экран и понять, что в прототипе стоит оставить по смыслу.

Снос Chakra и сборка на shadcn — дорожка C, после того как автор посмотрел живой прототип.

## Пока

Пакеты Chakra в `client/` не удалять в A/B. Не добавлять новые Chakra-компоненты и не возвращать `@chakra-ui/icons`.
