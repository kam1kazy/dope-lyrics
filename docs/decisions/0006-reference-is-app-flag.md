# ADR 0006 — Эталон не хештег в Telegram

Статус: принято
Дата: 2026-09-02

## Решение

В заметках нет тега `#эталон`. Эталон — флаг `Lyrics.isReference` в каталоге: ставит приложение, позже может ставить ИИ. Seed и парсинг чата этот флаг не трогают.

Фильтр карусели «тексты из демок» не делаем: эти тексты уже записаны, гонять их второй раз лентой нет смысла. Тег `#текст_с_демки` остаётся разметкой в чате; список демок — если понадобится отдельно, не как фильтр карусели.

## Почему

Хештег в чате — разметка письма. Эталон — оценка уже попавшего в каталог текста. Путать их нельзя: иначе полка пустая, а демки стоят рядом как будто это другое.

## Следствия

- GraphQL `referencesOnly` режет по `isReference`, не по тегам.
- Пока флаг некому ставить в UI, кнопки «Полка эталонов» в drawer нет.
- `demosOnly` в API и drawer нет.
- Писать эталон обратно в Telegram не планируем.
