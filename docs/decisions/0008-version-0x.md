# ADR 0008 — Версия продукта 0.x

Статус: принято
Дата: 2026-09-04

## Решение

Продукт живёт на **0.x**. `1.0.0` — только если автор сказал, что петлей уже пишут.

Правда — поле `version` в трёх `package.json` (корень, `client/`, `server/`), всегда одинаковое. Дневник — [docs/versions.md](../versions.md). `Version:` в vision/pillars/loop — черновик документа, не номер продукта.

## Когда ап

- **MINOR** (`0.4.0` → `0.5.0`) — закрыли дорожку или пачку OpenSpec, от которой экран другой. Не каждая спека. Несколько архивов за один заход — один ап. Чат **апнет сам**, без вопроса; в ответе скажет новую цифру.
- **PATCH** — обычно не трогаем. Шлифовка, доки, lint, тулчейн — не версия.
- `1.0.0` и коммит — только по просьбе.

## Почему

Личный инструмент, не магазин. Цифра нужна, чтобы через месяцы увидеть, какой это уже продукт, а не чтобы выкатывать релиз.
