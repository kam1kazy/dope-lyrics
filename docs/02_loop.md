# Как живёт автор

Пишет строку в Telegram или в Apple Notes
→ иногда ставит хештег или реакцию
→ забывает, потому что чат уезжает вверх
→ открывает Dope Lyrics
→ видит фразу снова (карусель; порядок можно случайный)
→ читает вслух, откладывает, склеивает, помечает эталон
→ позже просит инструмент собрать черновик из своих же строк
→ ещё позже — режим панчей: залететь на бит, пул по теме, лайк / свайп, из направления собрать текст

# Как живут данные

```
чат / канал с заметками
  → user-сеанс mtcute (не бот) читает историю
  → фильтр: текст, слова, абзацы, хештеги, реакции
  → JSON → Prisma → Postgres (source = TELEGRAM)

папка Apple Notes
  → AppleScript → .txt с YAML дат
  → zip или папка → import (CLI или /notes)
  → Postgres (source = APPLE_NOTES)

→ GraphQL `lyrics`
→ экран
```

Бот нужен для кнопок (`/bd`, `/notes`, `/chatid`, `/app`).
Заметки из чата читает аккаунт; Notes бот сам не видит — только скрипт и zip.

Домен нужен только чтобы открыть Mini App внутри Telegram
или держать бота, когда комп выключен.

# Экран

Карусель — способ чтения. Это и есть караоке: строки идут в темпе, их можно читать вслух. «Случайно» в drawer только меняет порядок той же ленты.

Отдельный режим караоке не планируем. Новые фичи чтения (подсветка, темп, и т.п.) наращиваются на эту карусель, когда понадобятся. Позже — шов жёлтый/зелёный на правках ИИ и своих вставках, если в ленту попадёт **сохранённый сгенерированный** текст; подсветку можно выключить. Карусель по-прежнему не режим генерации: панчи — отдельный режим. См. [roadmap E](./roadmap.md).
