# 004 — Экран на shadcn

Статус: done (kit)
Дорожка: C

## Зачем

Автор смотрел живой прототип и сменил kit до фильтров. Chakra снят, клиент на shadcn + FSD.

## Сделано

- нет `@chakra-ui/*` в `client/package.json`;
- слои `app` → `widgets` → `features` → `entities` → `shared`;
- карусель (она же караоке), пауза по клику;
- drawer на shadcn: порядок, типографика, теги, поиск — влияют на карусель;
- свайп вниз закрывает drawer;
- empty / error по-русски (ошибка API, пустой каталог, пустые фильтры);
- `bun run fix` на клиенте зелёный, `any` не было.

## Не в этом заходе

- композиция не обязана оставаться 640px — менять, когда понадобится.
- наращивать фичи чтения на карусель (не отдельный «режим караоке»).

## Не делать

- возвращать Chakra;
- править файлы в `shared/ui/shadcn/ui`;
- JWT, cookie-сессии, tenant;
- генерацию текста.
