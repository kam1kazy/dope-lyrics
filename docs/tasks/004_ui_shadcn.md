# 004 — Экран на shadcn

Статус: in progress
Дорожка: C

## Зачем

Автор смотрел живой прототип и решил сменить kit до фильтров. Chakra уже снят, клиент на shadcn + FSD.

## Сделано

- нет `@chakra-ui/*` в `client/package.json`;
- слои `app` → `widgets` → `features` → `entities` → `shared`;
- карусель, drawer «Фильтры», пауза по клику.

## Добить

- композиция чтения (не обязательно 640px);
- режимы карусель / караоке / рандом на новом kit;
- нормальные empty / error;
- не наращивать заглушки фильтров — живой запрос это дорожка D.

## Не делать

- возвращать Chakra;
- править файлы в `shared/ui/shadcn/ui`;
- JWT, cookie-сессии, tenant;
- генерацию текста.

## Готово когда

Экран читается на shadcn без Chakra, пустой список и ошибка API понятны по-русски. Фильтры могут ещё не ходить в GraphQL.
