# 005 — Карточка сообщения и каталог

Статус: закрыта; разрез/правка в `openspec/specs/lyric-split-and-edit` (архив `2026-09-03-lyric-split-and-edit`)
Дорожка: D (каталог) + кусок E (правка корпуса без модели)

## Зачем

Карусель умеет читать. Нужен каталог полок без отдельных страниц и без второго фильтра карусели под демки. Позже — резать и править фразу в каталоге, не возвращаясь в Telegram.

## Сделано

1. Боковое меню справа: иконка, выезд колонки, rail + панель.
2. Живые разделы: **Избранное**, **Тексты из демок**, **Сводка**, **Генератор** (сборка + история лайков).
3. Заглушка: Настройки ИИ — видна, выключена (эталоны / история генераций модели — не путать с историей склеек).
4. GraphQL: полки, `lyricDemos`, `lyrics(demoName)`, профиль, `catalogStats`, склейка/лайк.
5. Эталон — `isReference` в базе, не тег в Telegram. [`0006-reference-is-app-flag.md`](../decisions/0006-reference-is-app-flag.md).
6. Карточка (`MessageDeskDialog`): скрыть, избранное, эталон, цензура, профиль по ролям.
7. **Разрез** по стыкам строк и **правка** текста (двойной тап); теги дублируются на обе половины; выбор, какую часть оставить открытой. В Telegram не пишем.

## Ещё не ясно / долг

- Писать правки текста обратно в Telegram или только в свою базу? Сейчас — только база.
- После разреза слоты склейки с `startLine`/`endLine` на старый id могут врать — не чинили в этом срезе.
- Избранное vs `isReference`: два сигнала на практике ок, пока не схлопываем.
