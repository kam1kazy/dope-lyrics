# 005 — Карточка сообщения и полки

Статус: черновик, картинка неполная
Дорожка: D (продолжение каталога, не E)

## Зачем

Карусель умеет читать. Не умеет открыть целое сообщение, спрятать его, отметить избранным или собрать демки по имени. Автор пока не уверен, зачем именно sidebar и где граница с Telegram.

## Уже ясно

1. Эталон — не хештег в Telegram. Флаг `Lyrics.isReference` ставит приложение (позже ИИ). Парсинг и seed флаг не трогают. [`0006-reference-is-app-flag.md`](../decisions/0006-reference-is-app-flag.md).
2. Тег `#текст_с_демки` есть в чате. Фильтр карусели по нему не нужен: эти тексты уже записаны. Список демок — отдельный разговор, не полка на слайдах.
3. Telegram остаётся местом записи. Эталон в чат не пишем.
4. Бокового меню нет. Не собирать заранее.

## Ещё не ясно (не кодить вслепую)

- Писать правки текста обратно в Telegram или только в свою базу?
- «Скрыть» — флаг в каталоге или удаление? После следующего seed запись не должна всплыть, если скрытие живёт только локально и seed это не знает.
- Избранное vs `isReference`: два сигнала или один?
- Sidebar справа — каталог полок (демки, избранное, эталоны приложения) или меню? Drawer снизу уже держит фильтры; второй выезд не плодить «на всякий случай».
- Клик по строке карусели сейчас — пауза. Жест «открыть сообщение» не должен её сломать.

## Когда картинка сойдётся — тонкий первый срез

Не sidebar целиком. Сначала: из текущей фразы открыть **полное сообщение** (текст + теги + реакции) в диалоге. Дальше — включить `isReference` / скрыто / избранное, не полноценный редактор.

Список демок (если понадобится): не фильтр карусели, а каталог по имени (`#бисером` рядом с `#текст_с_демки`).

## Не делать в этом заходе

- ИИ, склейка (E);
- JWT / вход;
- править kit shadcn;
- писать эталон или правки в Telegram.
