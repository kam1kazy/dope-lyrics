# 005 — Карточка сообщения и каталог

Статус: в работе
Дорожка: D (продолжение каталога, не E)

## Зачем

Карусель умеет читать. Нужен каталог полок без отдельных страниц и без второго фильтра карусели под демки.

## Сделано

1. Боковое меню справа: иконка, выезд колонки, rail + панель.
2. Живые разделы: **Избранное** (список, пустое состояние), **Тексты из демок** (имена → полные тексты).
3. Заглушки: Эталоны, История генераций, Настройки ИИ — видны, но выключены.
4. GraphQL: `favoritesOnly`, `lyricDemos`, `lyrics(demoName)`.
5. Эталон — `isReference` в базе, не тег в Telegram. [`0006-reference-is-app-flag.md`](../decisions/0006-reference-is-app-flag.md).
6. Карточка сообщения из карусели (`MessageDeskDialog`): скрыть, избранное, эталон.

## Ещё не ясно

- Писать правки текста обратно в Telegram или только в свою базу?
- «Скрыть» после seed — не всплывает ли снова?
- Избранное vs `isReference`: два сигнала или один на практике?

## Следующий срез

- Открыть карточку из списка каталога с корректным обновлением кэша Apollo для `favoritesOnly` / `demoName`.
- Список демок: не фильтр карусели, только каталог.

## Не делать

- ИИ, склейка (E);
- JWT / вход;
- править kit shadcn;
