# 003 — Контролы каталога

Статус: first slice done (клиент)
Дорожка: D

## Зачем

Без порядка, тега и поиска нельзя нормально читать эталоны и случайные строки.

## Сделано (клиент)

1. Порядок: случайно / по порядку / обратно. Повторный тап по «случайному» заново перемешивает.
2. Теги — чипы из реальных хештегов, несколько, логика «хотя бы один». Пустой выбор = все.
3. Ключевые слова — подстрока без учёта регистра по тексту всего сообщения, не одной строки карусели.
4. Размер, межстрочие, скорость карусели — слайдеры, видно сразу.
5. Drawer закрывается свайпом вниз; слайдеры, поиск и теги жест не перехватывают.
6. Пустой список по фильтрам — «Нет текстов по выбранным фильтрам».

## Осталось

- аргументы фильтра в GraphQL `lyrics` (сейчас только `limit`/`offset`, отбор на клиенте);
- эмодзи, даты, полка эталонов.

## Не делать

- возвращать Chakra;
- править kit-файлы shadcn;
- генерация текста / GPT;
- JWT, cookie-сессии, Linux-хост.

## Готово когда (первый срез)

С сессии можно: пауза, рандом, выбор хештега, поиск по тексту — **сделано**.
Полный D — когда отбор умеет уходить в запрос и есть эталоны.
