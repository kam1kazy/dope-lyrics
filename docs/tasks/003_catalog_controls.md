# 003 — Контролы каталога

Статус: open
Дорожка: D

## Зачем

Фразы уже на экране, но это лента без руля: Play мёртвый, фильтры в меню не ходят в запрос.
Без этого нельзя нормально читать эталоны и случайные строки — ради чего каталог и поднимали.

## Сделать

1. Play / пауза управляет Viewport, а не просто картинка.
2. Сортировка: случайно, новые, старые.
3. Фильтр по хештегу (и пустой ввод = все).
4. По возможности — аргументы в GraphQL `lyrics`, не только фильтр на клиенте после полной выгрузки.

## Не делать

- снос Chakra и установка shadcn;
- генерация текста / GPT;
- сервер и домен;
- наращивать новые Chakra-виджеты «навсегда» — контролы можно временно на текущем UI.

## Готово когда

С сессии можно: пауза, рандом, выбор хештега эталона, и на экране только это.
