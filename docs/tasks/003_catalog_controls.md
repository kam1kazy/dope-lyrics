# 003 — Контролы каталога

Статус: open
Дорожка: D

## Зачем

Фразы на экране (shadcn). Пауза по клику есть. Поля фильтров в drawer не ходят в запрос.
Без сортировки и хештега нельзя нормально читать эталоны и случайные строки.

## Сделать

1. Сортировка: случайно, новые, старые.
2. Фильтр по хештегу (пустой ввод = все).
3. Аргументы в GraphQL `lyrics` (уже есть `limit`/`offset`), не только фильтр на клиенте после полной выгрузки.
4. Отдельная кнопка Play — только если на shadcn-экране без неё нельзя.

## Не делать

- возвращать Chakra;
- править kit-файлы shadcn;
- генерация текста / GPT;
- JWT, cookie-сессии, Linux-хост.

## Готово когда

С сессии можно: пауза, рандом, выбор хештега эталона, и на экране только это.
