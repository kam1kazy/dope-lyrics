# 001 — Локальный контур

Статус: open
Дорожка: A

## Зачем

Чаты и автор должны открыть экран на компе, даже с пустой базой.
Без этого нельзя проверить парсинг и дизайн.

## Сделать

1. Отдельная БД `dope_lyrics`: либо в уже живом Postgres, либо контейнер на `5433`.
2. Локальные `.env` с моками (не коммитить). Шаблон — [`../local.md`](../local.md).
3. `bun run setup` из корня.
4. `bunx prisma migrate dev --name init --skip-seed` из `server/`.
5. Клиент видит GraphQL на компе (`output: 'export'` сейчас бьёт в `/graphql` без прокси).
6. `bun run dev` без бота. Проверка: страница, пустой/ошибочный стейт, Prisma Studio.

## Не делать

- Прод-compose, nginx, SSL, Docker Hub
- Реальный `BOT_TOKEN` в репо
- Редизайн экрана
- Парсинг чата (это 002 / дорожка B)

## Готово когда

`localhost:3000` открывается, Yoga отвечает на `:4000/graphql`, таблицы есть в Studio.
