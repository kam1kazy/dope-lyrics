**Сделано (0.9.0)** — архив `2026-11-09-invite-only-signup`, `2026-11-09-profile-page`

- Регистрация только по приглашению: `/invite`, `/invites` в боте и блок «Приглашения» в профиле (`ADMIN`/`OWNER`).
- Профиль внизу меню: имя и роль, ⋮ → «Профиль» / «Выйти». Подкачка по своим источникам (привязанные каналы, у владельца — основной чат) в каталог нажавшего.
- Связь backend → бот между контейнерами (`telegram-bot:4071`, `INGEST_TOKEN`).
- Миграция `lyrics_chat_id`: `Lyrics.chatId`, дубли по паре чат + `lyric_id`; снят частичный уникальный индекс — он ронял разделение фраз на проде.
- Стенд 9.11: миграция прошла, backend видит бота, основной чат показал 55 новых. Не проверено руками: докачка из UI, приглашение из профиля со второго аккаунта, отказ незнакомому в Mini App.

**Сделано (0.8.0)** — архив `2026-11-09-multi-user-catalog`

- Схема: `UserRole`, `Session`, `ChannelBinding`, владелец у collage/history; частичный уникальный `(userId, source, lyric_id)`.
- Auth: `/auth/telegram-webapp`, `/auth/telegram-login`, refresh/logout/me; GraphQL по сессии или `initData`.
- Сверка с youways: CSRF и Origin на `/auth/*`, ротация сессии при старте (`navigator.locks`), 401 → экран входа, чистка сессий раз в сутки.
- Изоляция выборок и мутаций по `userId`; права через `can()`.
- Клиент: экран входа (Mini App молча, браузер — виджет), выход, PWA ставится на домашний экран.
- Стенд 9.11: миграция на проде, вход из Mini App и браузера проверен автором. Второй живой аккаунт не проверяли — изоляцию закрывают тесты.
- ADR [0009](../decisions/0009-user-auth-roles.md) отменяет 0007.
