Слова проекта. Если в коде другое имя — в скобках.

## Каталог

| Термин | Смысл |
| --- | --- |
| Фраза | Запись каталога (`Lyrics`): одна заметка из Telegram или Apple Notes. |
| Корпус | Все фразы автора. Личный, по `userId`. |
| Эталон | Фраза, которую автор считает сильной (`isReference`). Флаг в каталоге, не хештег в чате — [ADR 0006](./decisions/0006-reference-is-app-flag.md). |
| Грани | Настроение, подача, роль, энергия, готовность — профиль фразы. |
| Подача | Как строка читается: панч, флоу, хук, spoken, напев, адлиб, скороговорка. |
| Энергия | 1–5: шёпот … крик. |
| Полки | Избранное, эталон, скрытые, цензура, донор — фильтр в списке. |
| Донор | Фраза, вклеенная в другую (`isDonor`), прячется из ленты. |
| Карусель | Караоке: фразы по одной на экране, случайный порядок — это сортировка. |

## Генератор

| Термин | Смысл |
| --- | --- |
| Склейка | Трек из кусков своих фраз по форме (интро / куплет / хук / бридж), без модели. Хранит ссылки, не текст (`LyricCollage`). |
| Форма | Сколько каких частей в треке и какого размера. |
| Текст | Сохранённый результат генерации (`TrackText`), в карусель не идёт. |
| Скелет хита | Простой бит в MIDI для FL после одобренного текста: тональность, BPM и как исполнить строку. Звуки на дорожки автор ставит сам. Модель текста заранее пишет строки под этот шаг. Ещё не сделано. |
| Три снимка | «Из моих» (`sourceText`) → «ИИ» (`aiText`) → «Финал» (`finalText`). Первые два не меняются. |
| Шов | Подсветка происхождения слов: жёлтое — от модели, зелёное — от автора поверх модели. |
| Метка строки | В ответе генератора, до «Внести правки»: красный — переделать, зелёный — нравится и оставить. Не шов. |

## ИИ

| Термин | Смысл |
| --- | --- |
| Рамка | Инструкция задачи в коде (`COLLAGE_REWRITE_FRAME`, `FRAME_VERSION` в `server/src/modules/ai/rewrite/frame.ts`). Меняет разработчик. Версия — `MAJOR.MINOR.PATCH`: MAJOR — другой подход или этап, MINOR — новое правило или другое содержимое запроса, PATCH — формулировка. `1.0.0` — бывшая v13; старые записи `AiUsage` — `0.N.0`. С v9 строка не остаётся только потому, что написана: остаются якорь, звук находки и конкретный кадр. С v10 герой — персонаж, не исповедь; конкретику и абсурд можно приносить извне склейки. Вкус (кто герой, его мир) — в промпте автора, рамка общая для всех. С v11 образ с подтекстом не делается буквальным, мысль с конфликтом не выбрасывается ради рифмы, текст не сводится к двустишиям. Промпт автора в рамку не входит. |
| Промпт автора | Текст в «Настройках ИИ» с версиями (`AiPrompt`). Меняет автор. Идёт после рамки. |
| DNA | Описание стиля автора словами — то, что кладётся в промпт автора. |
| Режим «Свой» | Preserve: правка своей склейки с минимальным вмешательством (рамка v2). |
| Режим «Свободный» | Можно переписать фразу ближе к эталонам, сохранив смысл и структуру. Ещё не сделан. |
| «С нуля» | Explore: генерация без склейки, по теме и фильтрам. Отдельное действие. |
| Три задачи генератора | Будущий выбор в генераторе ИИ. 1 — переписать слабое, чтобы часть пелась, без нового чувства, факта и без смены порядка частей. 2 — собрать часть заново из её образов, сильные строки оставить, сюжет на весь трек не склеивать. 3 — цельный трек: связать части и дописать недостающее, смысл может сдвинуться, фонетические находки сохранить. |
| Описание отрывка | Своё пояснение к фразе или цепочке «что тут важно» — для модели. Ещё не сделано. |
| Расход | Учёт каждого вызова модели (`AiUsage`): модель, версии, токены, рубли. |
