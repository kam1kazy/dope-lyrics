# Прогон: промпт автора, тема и отсылки к новостям

12.11.2026. Склейка 8 (меланхоличная: косяк, одиночество, семья, терапия), рамка 2.0.0, модель `openai/gpt-6.1-terra`. Ответы — `server/.ai-probe/8/`, промпты — версии #1–#6 в «Настройках ИИ». 33 вызова, около 19 ₽.

Жалоба автора: текст «около литературный» — нет сленга, swag, грязи, отсылок к новостям и мемам.

## Что увидели

- **A, B, C почти одинаковые.** Промпт без темы регистр не сдвигает. Меланхоличная склейка остаётся меланхоличной: рамка держит мысль куплета и настроение, а образ («кадр странный и сжатый») даёт литературность — «семейное фото без рта», «тиски», «колыбели».
- **Тема — главный рычаг.** F и H дали флекс и иронию: «Терапия дороже, чем эти долги», «Я себе техподдержка: включи и забей», «Колыбельные в автотюне для стен / Я не сплю, зато вырубил всех соседей», «По нам не скажешь / По кэшу скажешь».
- **H (промпт автора + тема) — лучший баланс.** Мой добавочный блок в D–G вредил: модель вставляла фразы промпта дословно («деньги выше слабостей», «по нам не скажешь»), добавляла лишние четверостишия.
- **Примеры кодов копируются.** В C — «люблю зелень как корова на удалёнке в кутюрье», «большая дубина» в лоб. Принцип без примеров (D–G) дал свои коды, но модель залипла на одном («тамагочи» в 6 из 12) и **перекодировала авторский «косяк»** в «тамагочи» / «покемона». Правило «вещества только кодом» ломает собственные строки автора.
- **Новость модель не берёт, пока не заставить.** B–F, 19 ответов: Хуанга нет ни разу, даже с пояснением мема. В G (обязательная одна строка) — 3 из 3, но в лоб: «Я в кожанке Хуанга спалился на kiss-cam». Лучшее — «Кожанка Хуанга, мои глаза в 4K».
- **Отсылка через пометку строки — тоже пересказ.** Две красные строки, отсылка в теме, 3 прогона: «Монитор спалил Хуанга со шпионкой» (дважды), «Хуанг и шпионка, дымит монитор». Двойной смысл (монитор / слежка) есть, панча нет.
- **Пометки живой моделью:** 3 из 3 изменили только красные строки.
- **Обрывы.** `AI_MAX_TOKENS` по умолчанию 2048, ответ на склейку из 36 строк — около 1500 токенов. С промптом строки длиннее, 3 из 15 оборвались на лимите. Оборванный вызов оплачен полностью.

## Выводы

1. Направление трека задаёт тема, а не промпт. Промпт — персонаж, тема — что он сейчас делает.
2. В промпте — описание, без готовых строк и примеров: модель вставляет их дословно.
3. Коды веществ — не правило «только кодом», а разрешение: иначе модель перекодирует строки автора.
4. Свежая новость в общем промпте не работает. Отсылка — точечная задача на одну строку, и модели нужна зацепка (двойной смысл), иначе выходит пересказ. См. [ideas](../ideas.md#лента-мемных-новостей-как-источник-отсылок).
5. `AI_MAX_TOKENS` поднять до 4096: платим за фактические токены, потолок не дороже.
