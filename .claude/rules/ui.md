# Интерфейс

- Экран на **shadcn**. Chakra снят, не возвращать. Иконки — Lucide.
- Файлы kit (`shared/ui/shadcn/ui`) не редактировать: обёртки снаружи.
- Drawer фильтров живой: порядок, слайдеры, чипы тегов, ключевые слова. Свайп вниз закрывает; на слайдерах, поиске и тегах жест не перехватывать (`data-swipe-ignore`).
- Ошибки, пустые состояния, тосты, кнопки — по-русски. Не пускать в UI сырой GraphQL / Prisma / English (`Error`, `Required`).
- Менять только то, о чём задача. Не «случайно» ломать карусель и фильтры.
- Если трогаешь фильтры — они должны менять список, не быть декорацией.
- После UI-правок проверить в браузере сценарий: клик-пауза, свайп drawer, тег, поиск, пустой список, ошибка API. Не один скриншот. Если браузера нет — сказать, чем проверял.
- Не добавлять тесты на React / стили без просьбы.
- Кнопки-действия — иконками (Lucide), а не текстом. У каждой иконки без подписи — подсказка при наведении через `Hint` (`shared/ui/hint`) и `aria-label`. Новую кнопку-иконку без подсказки не добавлять; при правке старой — добавить.
